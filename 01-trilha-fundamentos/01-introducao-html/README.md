# 📚 Conteúdo estudado

## 📄 Estrutura básica do HTML

```html
<!DOCTYPE html>
<html>
<head>
    <title></title>
</head>

<body>

</body>
</html>
```

### Tags estudadas

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<title>`
- `<body>`

---

# 📝 Títulos

Foram utilizadas as tags de títulos:

```html
<h1></h1>
<h2></h2>
<h3></h3>
<h4></h4>
<h5></h5>
<h6></h6>
```

cada nível representa uma hierarquia diferente dentro da página.

---

# 📄 Textos

## Parágrafo

```html
<p></p>
```

## Span

```html
<span></span>
```

Utilizado para marcar pequenos trechos de texto.

---

## Formatação

### Negrito

```html
<b></b>
<strong></strong>
```

Diferença:

- `<b>` altera apenas o visual.
- `<strong>` indica importância semântica.

---

### Itálico

```html
<i></i>
<em></em>
```

Diferença:

- `<i>` possui apenas efeito visual.
- `<em>` adiciona ênfase ao conteúdo.

---

### Código

```html
<code></code>
```

Utilizado para exibir trechos de código.

---

### Citação

```html
<blockquote></blockquote>
```
Usado para destacar citações longas.

---

### Quebra de linha

```html
<br>
```

---

### Linha horizontal

```html
<hr>
```

---

### Sobrescrito

```html
<sup></sup>
```

Exemplo:

```
x²
```

---

### Subscrito

```html
<sub></sub>
```

Exemplo:

```
H₂O
```

---

# 📋 Listas

## Lista ordenada

```html
<ol>
    <li></li>
</ol>
```

---

## Lista não ordenada

```html
<ul>
    <li></li>
</ul>
```

---

## Lista de descrição

```html
<dl>
    <dt></dt>

    <dd></dd>
</dl>
```

---

# 🔗 Links

## Link básico

```html
<a href=""></a>
```

---

## Atributo href

Define o endereço do link.

```html
<a href="https://google.com">
```

---

### Target

### Nova aba

```html
target="_blank"
```

### Mesma aba

```html
target="_self"
```

### Página pai

```html
target="_parent"
```

### Janela principal

```html
target="_top"
```

---

# 🔖 Links internos

Criando um identificador:

```html
id="contato"
```

Criando um link para ele:

```html
<a href="#contato">
```

---

# 🖼️ Imagens

## Tag

```html
<img>
```

### Atributos

Caminho da imagem.

```html
src=""
```

Texto alternativo

```html
alt=""
```

Largura

```html
width=""
```

Altura

```html
height=""
```

---

## Figure

```html
<figure>

</figure>
```

Agrupa uma imagem.

---

## Figcaption

```html
<figcaption>

</figcaption>
```

Legenda da imagem.
